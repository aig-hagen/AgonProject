## Highlights

This release centers on a **reworked interactive tutorial system**: clearer hints,
better-targeted spotlights, and gesture instructions across the argumentation modules. It
also renames Documents to **Frameworks**, refreshes the editorial layout, and polishes
graph interaction with animated recentering and interactive node feedback.

## Tutorials

- Reworked tutorial hints, spotlight targets, and interactions across modules for a clearer,
  guided experience.
- Added gesture instructions for common actions, including collective attacks and argument
  creation.
- Enhanced the evaluation tutorial with improved spotlights and step interactions.
- Fixed formatting in the AF-basics tutorial.

## Frameworks

- Renamed Documents to **Frameworks** throughout the app.
- On mobile, track each framework's last-edited time and AF (argumentation framework) type.

## Graph interaction

- Added interactive node feedback and animated recentering of the graph.
- Dismiss the action bar when interacting outside it, with a `keepOpen` option for in-place
  toggles.
- Refined hyperlink creation in the graph editor on mobile.

## Editorial and help

- Updated the editorial style and layout for improved readability.
- Enhanced help gestures with clearer descriptions and new icons.
- Corrected poster wording and adjusted the author font size.

## Fixes and maintenance

- Updated the bundled graph component from 5.0.0-rc.20 to 5.0.0-rc.22.
- Use the aigblue brand color as the primary color on mobile.
- Updated end-to-end specs for the Documents → Frameworks rename.
- Removed obsolete mobile mockups and planning notes.
