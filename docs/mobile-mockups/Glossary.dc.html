EXTENSION SEMANTICS

Grounded extension

The unique minimal complete extension: accepts only what it can defend, committing to as little as possible.

Preferred extension

A maximal admissible set — no larger admissible set contains it. There can be several.

Stable extension

A conflict-free set that attacks every argument outside it.

CORE NOTIONS

Admissible set

A conflict-free set that defends each of its members against all attackers.

Conflict-free set

A set of arguments with no attacks between its members.
