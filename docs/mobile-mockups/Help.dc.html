How to edit
Double-tap the canvasAdd a new argument
Tap an argumentSelect its name and rename with the keyboard
Hold an argumentDelete it
Hold + drag to another argumentCreate an attack between them
Drag / pinchPan and zoom the canvas
Fit-view buttonRecenter everything if you lose the graph
Bottom-left selectorFor BAF/iAF: pick attack vs support, or definite vs uncertain, before you create
