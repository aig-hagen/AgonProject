# File formats

AgonProject supports portable documents and several export formats:

- [Native save format](./save-format.md) — versioned JSON documents used for saving, examples, and sharing.
- [ICCMA-style formats](./iccma-format.md) — the official AF text format and AgonProject extensions for other frameworks.
- [TGF-style formats](./tgf-format.md) — graph-oriented text exports and module-specific annotations.
- [LaTeX and TikZ](./latex-format.md) — generated `argumentation` package source and its rendered preview.
- [Graph SVG](./svg-format.md) — direct WYSIWYG serialization of the live editor canvas.

The native format is the application's portable compatibility contract. The remaining formats are exports; AgonProject does not import them.
