title: Assumption-based Argumentation Framework (ABAF)
reference: CFST18
---

An ABA framework is a tuple $D = (\mathcal{L}, \mathcal{R}, \mathcal{A}, \overline{\phantom{a}})$, where $(\mathcal{L}, \mathcal{R})$ is a [[abaDeductiveSystem|deductive system]], $\mathcal{A} \subseteq \mathcal{L}$ a set of [[abaAssumption|assumptions]], and $\overline{\phantom{a}} \colon \mathcal{A} \to \mathcal{L}$ a [[abaContrary|contrary function]].
