The contrary function $\overline{\phantom{a}} \colon \mathcal{A} \to \mathcal{L}$ of an [[ABAF]] maps each [[abaAssumption]] $a$ to its contrary $\overline{a} \in \mathcal{L}$. If a set of assumptions $S \subseteq \mathcal{A}$ [[abaDerivation|derives]] $\overline{a}$, then $S$ [[abaAttack|attacks]] $a$.
