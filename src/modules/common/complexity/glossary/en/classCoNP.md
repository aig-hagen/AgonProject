---
label: $\mathsf{coNP}$
title: Complexity Class $\mathsf{coNP}$
---

The decision problems for which every instance $x$ has a set of potential witnesses of size polynomial in $|x|$ such that checking whether a potential witness is valid takes polynomial time, and $x$ is a yes-instance if and only if no witness is valid. These are the complements of the problems in [[classNP|$\mathsf{NP}$]].
