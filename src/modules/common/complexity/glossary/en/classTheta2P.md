---
label: $\Theta_2^{\mathsf{P}}$
title: Complexity Class $\Theta_2^{\mathsf{P}}$
---

The decision problems decidable by a deterministic polynomial-time algorithm that may make a logarithmic number (in the input size) of calls to an [[classNP|$\mathsf{NP}$]] oracle, written $\Theta_2^{\mathsf{P}} = \mathsf{P}^{\mathsf{NP}}[\log]$. Equivalently, the algorithm may make linearly many non-adaptive oracle calls, all evaluated in parallel; the class is then also written $\mathsf{P}^{\mathsf{NP}}_{\parallel}$.
