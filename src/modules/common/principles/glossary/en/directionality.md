---
label: directionality
title: Directionality
---

A [[semantics]] $\sigma$ satisfies directionality iff for every framework $F$ and every unattacked set $U$, $\sigma(F|_U) = \{E \cap U \mid E \in \sigma(F)\}$. A set $U \subseteq A$ is unattacked if no argument in $A \setminus U$ attacks an argument in $U$.
