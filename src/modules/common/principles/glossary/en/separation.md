---
label: separation
title: Separation
---

A [[semantics]] $\sigma$ satisfies separation iff for every framework $F$ and every unattacked set $U$ with $\sigma(F|_U) = \{\emptyset\}$, $\sigma(F) = \sigma(F|_{A \setminus U})$. A set $U \subseteq A$ is unattacked if no argument in $A \setminus U$ attacks an argument in $U$.
