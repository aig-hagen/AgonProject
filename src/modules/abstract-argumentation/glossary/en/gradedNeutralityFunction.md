---
label: graded neutrality function
title: Graded Neutrality Function $n_m$
reference: GM15
---

For an [[AF]] $F=(A,R)$, a set $X \subseteq A$, and an integer $m \geq 1$, the graded neutrality function is defined by $n_m(X) = \{x \in A \mid |\{y \in X \mid (y,x) \in R\}| < m\}$. A set $X$ is $m$-conflict-free iff $X \subseteq n_m(X)$.
