label: AF
title: Argumentation Framework (AF)
reference: D95
---

An argumentation framework $F = (A, R)$ consists of a finite set of arguments $A$ and an attack relation $R \subseteq A \times A$. We write $a \to b$ if $(a,b) \in R$, meaning $a$ attacks $b$.
