---
label: propagation
title: Propagation Ranking
---

The propagation ranking assigns each argument an initial value and propagates it along attack paths to obtain a propagation vector, which is turned into a ranking $\succeq_F^\mathrm{Prop}$ on $A$ using one of three variants (Propa$_\epsilon$, Propa$_{1+\epsilon}$, Propa$_{1\to\epsilon}$). Note that this ranking is only implemented for acyclic AFs.
