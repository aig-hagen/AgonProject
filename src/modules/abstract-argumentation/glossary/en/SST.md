A set $E \subseteq A$ is a semi-stable [[extension]] iff $E$ is [[CO|complete]] and there is no complete extension $E'$ with [[range|$E^\oplus$]] $\subsetneq E'^\oplus$.

## Signature

A set $\mathbb{S}$ of sets of arguments is in [[signature|$\mathsf{sig}(\mathsf{sst})$]] iff $\mathbb{S} \neq \emptyset$, $\mathbb{S}$ is incomparable and conflict-sensitive [@DDLW15].
