A set $E \subseteq A$ is the ideal [[extension]] iff $E$ is the $\subseteq$-maximal [[ADM|admissible]] set with $E \subseteq \bigcap$ [[PR|$\mathsf{pr}(F)$]].

## Signature

A set $\mathbb{S}$ of sets of arguments is in [[signature|$\mathsf{sig}(\mathsf{id})$]] iff $\lvert\mathbb{S}\rvert = 1$ [@DSLW16].
