A set $E \subseteq A$ is the eager [[extension]] iff $E$ is the $\subseteq$-maximal [[ADM|admissible]] set with $E \subseteq \bigcap$ [[SST|$\mathsf{sst}(F)$]].

## Signature

A set $\mathbb{S}$ of sets of arguments is in [[signature|$\mathsf{sig}(\mathsf{ea})$]] iff $\lvert\mathbb{S}\rvert = 1$ [@DSLW16].
