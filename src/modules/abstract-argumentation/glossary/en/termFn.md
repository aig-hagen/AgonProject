---
label: termination function
title: Termination Function $\beta$
reference: T22
---

A termination function is any function $\beta$ that maps each state $(F, E)$, with $F$ the current [[reduct]] and $E$ the set of arguments selected so far, to $\{0,1\}$; $\beta(F,E) = 1$ means the construction may end in this state.
