label: semi-qualified
title: Semi-Qualified Semantics
symbol: \mathsf{sq}\text{-}\sigma
reference: DRT20
---

Given an [[sccDecomposability|SCC-decomposable]] [[semantics]] $\sigma$, the semi-qualified semantics [[labelling|labels]] each [[scc|SCC]] like $\sigma$, but treats an attacker from an earlier SCC that is labelled $\mathsf{undec}$ as $\mathsf{out}$ exactly when no other labelling of these attackers labels it $\mathsf{in}$ (see [[semiQualifiedLocalFn]]).
