---
label: semi-qualified
title: Semi-Qualified Semantics
---

Given an [[sccRecursive|SCC-decomposable semantics]] $\sigma$, semi-qualified $\sigma$-semantics evaluates each [[scc|SCC]] using the [[semiQualifiedLocalFn]]. This treats an undecided outparent as out only when no alternative labelling of the SCC's outparents labels it in.
