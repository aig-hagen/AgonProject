A set $E \subseteq A$ is a preferred [[extension]] iff $E$ is a $\subseteq$-maximal [[CO|complete]] extension.

## Signature

A set $\mathbb{S}$ of sets of arguments is in [[signature|$\mathsf{sig}(\mathsf{pr})$]] iff $\mathbb{S} \neq \emptyset$, $\mathbb{S}$ is incomparable and conflict-sensitive [@DDLW15].
