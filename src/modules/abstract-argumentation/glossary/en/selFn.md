---
label: selection function
title: Selection Function $\alpha$
reference: T22
---

A selection function is any function $\alpha$ that maps three sets $X, Y, Z$ of sets of arguments to a set $\alpha(X,Y,Z) \subseteq X \cup Y \cup Z$. Applied to the [[unattackedInitial|unattacked]], [[unchallengedInitial|unchallenged]], and [[challengedInitial|challenged]] [[IS|initial sets]] of the current [[reduct]], it selects those eligible in the next step.
