label: ADF
title: Abstract Dialectical Framework
---

An abstract dialectical framework $D = (A, L, C)$ consists of a set of arguments $A$, a set of links $L \subseteq A \times A$, and for each argument $a \in A$ an [[acceptanceCondition]] $C_a$ over its [[parents]] $par(a)$.
